# 제품 유형 모듈

`--type=auto`면 첫 페이지를 본 뒤 고른다. 애매하면 `web-saas`.

## web-saas

필수: 지도, 표면, 카드, 지금 미는 것, 외부·역사, 런타임 네트워크·응답시간, 대표 시도.

해당 없음으로 두는 절: 모델·라우팅·코칭, CLI 덤프(웹만이면).

## widget-llm

웹 SaaS 칸에 더한다.

- 위젯 JS·conf JSON·talk/chat API
- 모델명 탐색 7단: JS 문자열 → conf JSON → 요청 필드 → 응답·스트림·헤더 → 오버라이드 → 프롬프트 엔드포인트 → 페르소나 질문
- 페르소나·거절·핸드오프 재구성. 시스템 프롬프트 전문이라고 쓰지 않는다
- WebFetch가 비어도 페이지가 빈 것이 아니다

판정:

| 관측 | 쓸 수 있는 문장 |
|---|---|
| 문자열·헤더·응답에 모델 ID | 모델명 확정 |
| 다이얼/라우트만 | 사용자는 난이도만 고른다. 실제 모델은 문서로만 |
| 거절·404·무시 | 미확인. 우회 단서는 별도 줄 |
| 페르소나 누출 | 코칭 재구성. 시스템 프롬프트 전문이 아니다 |
| 자매 제품의 클라우드 | 우회 단서. 이 제품 엔진이 아니다 |

## cli-agent

웹 SaaS 칸에 더한다.

- 이미 설치된 바이너리만 읽기 전용으로 덤프한다. 공식 설치는 승인+`mutations_allowed`가 둘 다 있기 전에는 지시하지 않는다
- help / tools list / execute init / 플러그인 옵션을 따로 찍는다
- 도구 개수가 명령마다 갈리면 표로 남긴다
- 첫 쿼리 후 과금 게이트면 같은 실패를 반복하지 않는다
- Dial·모드·모델 카드가 있으면 라우팅 표

## 공통 실제 시도

지도만 그리고 끝내지 않는다. 대표 시도는 기본 0건이다. 승인과 `mutations_allowed`에 정확한 액션이 있을 때만 읽기 전용 1건을 보낸다.

- 검색/읽기 전용 데모/상태 조회 중 공개된 것
- 쓰기가 필요하면 “Do not edit any files.” 또는 스킵
- 승인된 1건의 네트워크·응답시간을 런타임 실측의 시드로 쓴다
