# 런에서 일반화한 규칙

출처를 스킬 본문에 되풀이하지 않는다. 같은 일이 나면 `notes/skill-notes.md`에 한 줄을 더한다.

## Amp (2026-08-14)

- `sitemap-behind-login`: 사이트맵이 로그인 뒤에 있을 수 있다. 막힌 사실을 남기고 네비로 다시 그린다
- 브랜드 명사는 번역하지 말고 `id`로 고정한다
- 기능 삭제가 전략이다. 카드에서 빼면 오독한다
- 도구 목록은 `list` / execute init / 플러그인 옵션이 갈린다
- changelog 클레임과 일반 쿼리를 섞지 않는다
- 일회용 포털 로그인 코드는 덤프에서 지운다

## PRizmo (2026-08-13)

- `static-empty-widget`: 정적 원문 열람이 비어도 위젯 페이지가 빈 것이 아니다. 브라우저 렌더와 원문·네트워크를 교차 확인한다
- 모델명 탐색: JS 문자열 → conf JSON → 요청/응답/헤더 → 오버라이드 → 프롬프트 엔드포인트 → 페르소나 질문
- 클라이언트에 없으면 모델명은 미확인이다. 자매 제품은 우회 단서일 뿐 엔진 증명이 아니다
- 페르소나 재구성은 시스템 프롬프트 전문이 아니다
- 공개 없는 ARR/MAU는 공백이다
- 공식 요금과 제3자 요금이 갈리면 표로 고정한다
- 큰 PNG는 phantom page를 만든다. jpg 1400px + 캡션을 이미지 앞 + max-height
- extra CSS의 `{{FONT_DIR}}`는 치환되지 않는다. 폰트는 절대경로 + `!important`

## aitestbed (2026-08-07)

- 공식 site-map + GNB + 번들 라우터를 교차한다
- 호스트가 여러 개면 지도를 호스트별로 나눈다
- 포인트/원/토큰 단위를 한 칸에 섞지 않는다
